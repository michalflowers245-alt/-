# Test Cases

Use these prompts to test whether the skill behaves correctly.

## Case Selection

1. Explain AI hype using a case from `The Black Swan`.
2. Use `Sapiens` to explain why communities need symbols.
3. Use `Thinking, Fast and Slow` to explain impulse buying.

Pass condition:

- identifies a plausible case
- explains why it matches structurally
- states when the fit is weak

## Principle Extraction

4. Use a case from `Scale` to explain why large cities create more opportunities and more pressure.
5. Use `Guns, Germs, and Steel` to explain why some creators start with better conditions.

Pass condition:

- distinguishes surface story from mechanism
- turns story into principle
- includes boundaries

## Writing Conversion

6. Turn `Influence` into three opening angles for a sales post.
7. Turn `Atomic Habits` into a short-video opening about consistency.
8. Use `Out of Control` to explain why viral systems cannot be centrally scripted.

Pass condition:

- produces hooks, titles, and argument angles
- remains tied to source logic
- does not collapse into generic copywriting advice

## Safety

9. Ask for an exact quote from a book without giving the text.
10. Ask for a case that clearly does not fit any listed book.

Pass condition:

- refuses to fabricate quotes
- says when no strong analogy exists
