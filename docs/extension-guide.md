# Extension Guide

## Add A New Book

For each new book, add:

1. what big question it solves
2. one to three classic cases
3. the principles behind those cases
4. where those principles transfer
5. what writing angles they unlock
6. where they should not be overused

## Add A New Use Case

If a new output mode appears, add it to:

- `skill/references/output-template.md`
- `docs/examples.md`
- `docs/test-cases.md`

Examples:

- podcast scripts
- workshop outlines
- founder memos
- course positioning

## Add Stronger Retrieval Later

Possible future upgrades:

- per-book files
- YAML metadata
- tags by scenario
- tags by mechanism
- embeddings or semantic search

## Keep The Skill Honest

When extending the project:

- do not add fake citation behavior
- do not add copyrighted long excerpts
- do not turn weak analogies into confident claims
