# Naming Notes

## Candidates

1. `brief-history-thinking-skill`
2. `big-book-analogy-skill`
3. `classic-case-transfer-skill`
4. `analogy-to-argument-skill`
5. `case-to-principle-writing-skill`

## Final Choice

`case-to-principle-writing-skill`

## Why

- `case` captures the skill's first move.
- `principle` captures the abstraction layer.
- `writing` captures the applied use case.
- It works well as a repo name and a concept name.
