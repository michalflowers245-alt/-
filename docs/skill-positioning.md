# Skill Positioning

## Essence

This is not a reading-note skill.

It is:

> a thinking and writing aid that uses cases, models, and analogies from classic popular books to help users explain reality clearly, simply, and persuasively.

## Target Tasks

- topic planning
- video copy
- newsletter or public-account essays
- long X/Twitter threads
- business analysis
- product storytelling
- social-issue explanation
- personal-growth expression
- simplifying complexity
- argument design

## The Real Job

When a user asks a question, the skill should first ask:

> What known case from this book set is this most like?

Only after that should it move to:

- what principle the case reveals
- why that principle works
- how it maps onto the user's context
- how to turn it into writing

## What Good Output Feels Like

- concrete before abstract
- story before lesson
- mechanism before slogan
- transfer before title
- useful without pretending certainty

## Failure Modes To Avoid

- generic "this tells us" summaries
- fake textual authority
- forcing weak analogies
- using book names as decoration without real transfer
- replacing explanation with vibes
