# Safety Rules

## Anti-Hallucination

Never claim:

- exact quotes without the text
- exact page numbers without verification
- exact chapter placement without verification
- that every book has been fully read in this session

Preferred wording when source access is indirect:

- `The core idea of the book here can be summarized as ...`
- `A representative case often used to explain this is ...`
- `This is a high-confidence summary, not a verbatim quote.`

## Copyright Compliance

Do not provide:

- full book text
- pirated copies
- long copyrighted excerpts

Allowed:

- short, lawful summaries
- high-level retellings of cases
- conceptual paraphrase

If the user asks for precise wording:

- ask for the excerpt
- or explain at a summary level instead

## Boundary Discipline

Say no when:

- no strong analogy exists
- the requested transfer would distort the source
- current facts matter more than book analogies

## Writing Safety

Do not let style outrun truth.

If the analogy is elegant but weak, downgrade it or reject it.
